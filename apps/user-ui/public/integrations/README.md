# Integration logos

Local assets for connected accounts and the app catalog. SVG originals come from
[SVG Logos](https://github.com/gilbarbara/logos), pinned at `4a5b550414be64d5c007574cd395d910d50e8950`
(CC0 collection license included). Google Docs/Sheets files are from Google’s
first-party asset host; the Fathom favicon is linked by https://fathom.ai. Brand
marks belong to their respective owners. Assets retain their original colors and
are served locally without remote image requests. Unknown apps use a generic
application icon rather than an invented brand mark.
