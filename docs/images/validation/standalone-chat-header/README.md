# Standalone chat header validation

Synthetic local owner/Puff direct chat against the real Nest product API and
unchanged pinned OrgOps engine. No production messages, accounts or credentials.
Screenshots show the implemented desktop (1440×1290) and mobile (390×844) UI
for a connection-return URL containing a synthetic connected-account identifier.

`npm run test:ui:dashboard` covers the header, actual direct-chat access, reload,
account/settings/notifications, channel filtering, mobile navigation, composer
visibility, and exactly one header in project chats.
