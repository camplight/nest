# Unified project workspace

Synthetic local fixture accounts/projects only, captured by the real product/engine
browser harness in tests/browser/projects.ts. Model naming uses an injected delayed
fixture; no live model or production tenant data is shown.

The desktop panel and mobile disclosure replace duplicate Members navigation.
Inline editing, counts, search-based invitations and automatic personal-agent
participation are product extensions using the existing Nest design tokens and
avatars. Personal connected-account access is intentionally unchanged; the draft
explains that project participation pauses connected tools under the existing rule.

Validation: 145 product tests, lint, build, project and dashboard browser checks.
The normal mobile view is collapsed; its details remain available from the summary.
